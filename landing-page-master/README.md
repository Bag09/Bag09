# Landing Page Master

Самодостаточный навык для Claude Code: исследует задачу, строит структуру, пишет доказательный текст и генерирует быстрый доступный лендинг на русском. Он применим к B2B/B2C, сервисам, продуктам и экспертам; отдельный модуль описывает медицинскую технику и инженерную эксплуатацию.

## Быстрый старт

Откройте `SKILL.md`, затем последовательно используйте `methodology.md`, нужные блоки и чек-листы. Для заявки и публичной витрины статусов скопируйте шаблон `templates/landing.html` и компоненты `templates/charts.js`. Цифры в шаблоне — демонстрационные: перед публикацией замените их данными API или уберите.
