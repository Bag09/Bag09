# Копирайтинг: ясность раньше украшения

## Формулы

- **4U:** полезность + срочность + уникальность + конкретика. «Вернём критичное оборудование в план работ: первичная реакция по SLA до 15 минут».
- **PAS:** проблема → цена бездействия → решение. «Простой анализатора сдвигает поток исследований. Диспетчер фиксирует приоритет и направляет сертифицированного инженера.»
- **AIDA:** внимание → интерес → желание → действие. Подходит для hero и промо, не заменяет доказательства.
- **BAB:** до → после → мост. «Вместо звонков в разные службы — один номер заявки и прозрачный путь до закрытия.»
- **FAB:** характеристика → преимущество → выгода. «Дежурная очередь 24/7 → быстрое назначение → отделение понимает, когда вернётся к работе.»

## Шаблоны секций

**Hero:** «[Результат] для [роли] без [главный риск]» + «[как достигается]» + CTA + проверяемое условие.

**Преимущество:** «[Механизм], поэтому [измеримая польза]». Не «индивидуальный подход», а «единая карточка объекта хранит историю работ и согласованный приоритет».

**Кейс:** исходная ситуация → ограничение → действие → результат с периодом → чему это обязано. Если результат нельзя назвать — расскажите процесс, не имитируйте цифры.

**FAQ:** вопрос формулирует настоящее возражение, ответ сначала даёт прямой вывод, затем условия и следующий шаг.

## Два направления как одна система

Дайте единую выгоду («одна заявка — контролируемый путь»), затем два явно подписанных маршрута. Используйте неизменные термины: «Инженерные системы» и «Медицинская техника». Описывайте не каталог ради каталога, а сигнал маршрутизации, SLA и результат для отделения.

## Редактура

Проверяйте: кто делает что, для кого, при каких условиях, когда и как это проверить. Заменяйте канцелярит глаголом, абстракцию примером, обещание доказательством. Один абзац — одна мысль; длинное объяснение делите подзаголовками и списками.
